## About the project

The files stored in this repository act as a collection of software resources to supplement and drive the brains of our autonomous wheelchair robot. The files stored in this repository may include but are not limited to, package files, 3d models, URDF robotics files, memos, or other important project software or documentation. This repostiory will serve as a tool for us to acess project files from a variety of systems to streamline workflow throughout our timeline.

## Helpful Info
